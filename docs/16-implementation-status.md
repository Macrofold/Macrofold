## Important invariants exercised

Tenant selectors cannot grant ownership; scoped operations authorize their underlying project; provider/connection grants remain current at call time. Mutations retain their idempotency identity across lost responses. A lost native-launch acknowledgement does not repeat the prompt. Unknown usage remains visible instead of becoming a false zero. Credit reservations, immutable journals and independent reconciliation protect concurrent spending.

File persistence, execution outcome and Git publication are independent. Failed runs retain verified partial files; unavailable execution copies remain explicit recovery states. Git pushes never force-update a protected branch. Transfers check revision/hash/local preconditions and reject traversal, metadata aliases, unsafe Windows names and symlink ancestors. Archive metadata cannot collide with a customer's `manifest.json`.

Detailed run content expires by plan while terminal/accounting identities remain. Project deletion is delayed and reversible before purge; object collection has an additional delay and traverses manifest reachability. Raw request/activity facts retain 400 days and older reports expose missing sources. Operator audit rows are immutable. General metrics/logs exclude prompts, files, request bodies and credentials.

## Known launch boundaries

The current production compute adapter is Vercel Sandbox. The standalone Node/Docker control plane and SQL poller are implemented; a second production compute vendor, cross-vendor memory snapshots and one-click provider migration are not. Portable file/Git/native-home recovery is the tested migration foundation.

The initial terminal targets are macOS/Linux. Windows install/ACL/TTY verification and public registry publishing/provenance remain release tasks before advertising Windows support. The dashboard has one light content theme, compact tool/event inspection and checkpoint/file views; it is not a collaborative editor, raw remote terminal, browser desktop or full artifact-review suite. Browser automation can be added through an independently reviewed tool integration. Enterprise SSO/SCIM and arbitrary customer images are outside this launch.

Infrastructure reports cover authoritative platform facts and explicitly disclose missing vendor CPU/quota/invoice readers. They do not constitute a production throughput benchmark or provider invoice reconciliation. Management agents are read-only; deployment changes, financial decisions and whole-account closure follow operator procedures. Automated accessibility checks are not a full assistive-technology certification.
