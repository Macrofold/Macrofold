# Task and feature routes

Complete [root guidance](../../../AGENTS.md) first. This map selects the affected owners after the mandatory baseline; it is not another mandatory bundle. Read applicable scoped instructions even for a new file. Trace the union of affected paths for a cross-layer change, then revisit scope as callers emerge.

## Development lifecycle

| Request                                                     | Procedure and completion boundary                                                                                                                                                                                                                                             |
| ----------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Implement/fix/refactor                                      | Inspect current work and status, plan the full outcome, prepare the base through [Rebase](../../../.agents/skills/macrofold-rebase/SKILL.md), trace owners/callers, implement, verify under [TESTING.md](../../../TESTING.md), inspect the full diff and reconcile docs/TODO. |
| Feature spec, technical design, architecture                | [Design](../../../.agents/skills/macrofold-design/SKILL.md), [project index](../../projects/README.md) and existing feature/architecture owners. Design alone does not authorize implementation.                                                                              |
| “Approved”, “do it”, “continue” referring to an agreed plan | Resolve the discussed scope and remaining work; use Design's approval/continuation path without another confirmation. Honor exclusions and “do not implement yet”.                                                                                                            |
| Review or fix review findings                               | [Review](../../../.agents/skills/macrofold-review/SKILL.md) and [review rules](../../../.agents/rules/code-review.md); findings-only/review-only stays read-only, authorized fixes include verification and documentation.                                                    |
| Rebase or merge conflict                                    | [Rebase](../../../.agents/skills/macrofold-rebase/SKILL.md); an uncertain resolution stops all work and preserves the conflicted state for the developer's decision.                                                                                                          |
| Instructions/skills/routing                                 | [Guidance maintenance](../../../.agents/skills/macrofold-guidance/SKILL.md), affected policy, adoption record and dispatch cases. Reading a workflow for maintenance does not execute it.                                                                                     |
| Documentation-only change                                   | [Documentation rules](../../../.agents/rules/documentation.md), affected owners and `pnpm docs:check`; do not run application or paid workflows just because they are mentioned.                                                                                              |
