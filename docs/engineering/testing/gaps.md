## Remaining gaps

- GitHub social login and authenticated email delivery, OAuth consent registries, live Stripe ordering/reconciliation, model/sandbox limits, object-storage transfer failures and actual cloud Workflow replay require the [pre-deployment checks](../../operations/pre-deployment.md). Local protocol fixtures cannot prove hosted vendor behavior.
- Broader combinations in account authentication, external MCP OAuth, GitHub installation callbacks and large lifecycle orchestration still need focused failure assertions. Passing branch floors is not a reason to stop auditing those paths.
- Credential-lock ownership, stale-lock recovery, invalid permissions/symlinks/JSON, device responses and expiry now have focused assertions. These do not cover every disk-full/rename interruption or Windows ACL behavior.
- Browser JavaScript coverage is Chromium-only. Async server components require application/browser acceptance; direct function invocation does not prove routing or hydration.
- Native SDK/binary internals are excluded, and abruptly terminated native workers can lose unflushed counters. Their existing network-disabled execution/restore/input acceptance remains essential.
- Restore tests now kill actual processes around individual file and checkpoint-index publication, then retry. They do not establish power-loss durability or whole-directory transactional replacement. Partial restore must only target an unstarted replacement sandbox, as the implementation requires.
- Worker-kill/long-duration load tests remain independent capacity evidence. Do not interpret coverage totals as a new throughput measurement.

The [focused acceptance record](sdk-and-draft-acceptance.md) records the current test totals and measurement limits.

The [mutation reference](mutation.md) records surviving mutations and scope decisions. Add evidence at the smallest boundary that can detect the defect: transaction races in real PostgreSQL, file integrity on disposable files, transport fixtures for providers, and browser/terminal tests for wiring and interaction.
