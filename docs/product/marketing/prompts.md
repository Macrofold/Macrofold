# Hero image prompts

These ten original posters were generated with the built-in image-generation tool. The PNG originals live in `apps/web/public/concepts/`; the website uses Next.js responsive image delivery. No reference-company images or logos were copied. These are concept frames, not finished animations. Motion specifications live in the [concept catalog](../../../apps/web/components/concepts/catalog.ts).

## aurum

Use case: stylized-concept. Asset: premium abstract hero artwork for an AI developer infrastructure website, not a website screenshot. Wide landscape composition, 1536x1024. Sophisticated computational physics / machine learning aesthetic, precise engineered detail, physically convincing light, extraordinary but restrained, large coherent forms and generous negative space, outstanding art direction. No text, letters, labels, UI, logos, people, laptops, cloud icons, planets, stars, trees, botanical branching, toy shapes, rainbow gradients, or decorative science equations. This is inspirational abstract artwork, NOT a literal diagram of agents or infrastructure. A sculptural, folded gold micro-mesh membrane, hundreds of extremely fine parallel metallic threads forming an undulating computational surface, sharp ridges and recessed folds. One concentrated object positioned center-right, obsidian-black background, champagne gold specular highlights and tiny subtle spectral fringe along an edge. Matte shadows, raking studio light, no gold cube, no torus. Quiet high-end physical material, subtle precision.
