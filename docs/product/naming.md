# Twenty possible names

Alternative naming concepts considered for the project, now presented publicly as Macrofold. Meanings below are concise historical/scientific associations, not claims of ownership or uniqueness. Domain, trademark, repository, app-store, pronunciation, and regional-language checks are required before selecting a name; no availability claim is made here. The initial five-name collision screen below is based on public product pages, not a trademark review.

| Name | Pronunciation | Association | Why it fits | Branding consideration |
|---|---|---|---|---|
| Noesis | noh-EE-sis | Intellectual apprehension | A thoughtful, capable working agent | Philosophical term already used in software/services |
| Ariadne | air-ee-AD-nee | Mythic guidance through a labyrinth | Continuing work through complicated projects | Elegant but spelling/pronunciation vary |
| Clio | KLEE-oh | Muse of history | Persistent records and inspectable work | Strong existing commercial associations |
| Thales | THAY-leez | Early Greek philosophy and mathematics | General inquiry and practical reasoning | Major established technology/defense brand |
| Hypatia | hy-PAY-shuh | Historical mathematician and philosopher | Learning, rigor, and independent thought | Distinctive but four syllables |
| Kepler | KEP-ler | Mathematical description of planetary motion | Reliable coordination and discovery | Widely used name in science/software |
| Hestia | HES-tee-uh | Hearth and continuity | A lasting home for projects and agents | Softer positioning; existing software uses |
| Telos | TELL-oss | Purpose or end | Work directed toward an outcome | Short but heavily used abstract brand term |
| Praxis | PRAK-sis | Practice and purposeful action | An agent that does useful work | Many established uses |
| Monad | MOH-nad | A unit in philosophy and mathematics | A self-contained execution abstraction | Strong software/crypto associations |
| Nous | NOOSS | Mind or intellect | Minimal, intellectual identity | Pronunciation and French association need testing |
| Ananke | uh-NANG-kee | Necessity in Greek thought | Dependable work and constraints | Less obvious spelling; austere connotation |
| Orbis | OR-biss | Circle/world | A place for connected, continuing work | Broad existing company usage |
| Quipu | KEE-poo | Andean knotted record system | Persistent state and structured records | Use cultural reference respectfully; spelling needs teaching |
| Lyceum | ly-SEE-um | A place associated with learning | A home for capable collaborators | Educational rather than infrastructure association |
| Tessera | TESS-er-uh | A small piece of a mosaic | Independent agents contributing to a coherent whole | Existing company/product usage |
| Palimpsest | PAL-imp-sest | A surface bearing layers of writing | Versioned files and accumulated work | Strong concept; long and difficult to spell |
| Lumen | LOO-men | Light; luminous-flux unit | Clarity and visibility into complex work | Very crowded technology branding |
| Metis | MEE-tiss | Practical wisdom in Greek thought | Adaptable, resourceful agents | Pronunciation and cultural/name overlap need care |
| Asterion | ass-TEER-ee-on | A name associated with stars in Greek tradition | A distinctive identity with room to grow | Mythological associations vary and need audience testing |

The initial conceptual shortlist was Noesis, Ariadne, Hestia, Quipu, and Tessera. Public research found relevant existing usage for all five:

| Candidate | Verified existing use | Consequence for further naming work |
|---|---|---|
| Noesis | [Noesis.tech](https://www.noesis.tech/about) describes AI/software services; [Noesis Corporation](https://www.noesis-corporation.com/about-noesis/who-we-are) provides technology consulting | Significant technology-category crowding |
| Ariadne | [ariadne.ai](https://ariadne.ai/) offers AI image-analysis products | Existing exact-name AI association |
| Hestia | [Hestia Control Panel](https://hestiacp.com/) is an open-source server management product | Existing infrastructure/software association |
| Quipu | [TeamSystem Quipu](https://getquipu.com/) offers invoicing software | Existing SaaS brand |
| Tessera | [Tessera Labs](https://www.tesseralabs.ai/product) describes AI automation; [TesseraOS](https://github.com/TesseraOS/Tessera) describes an AI coding-agent context/memory platform | Particularly close category overlap; deprioritize as a launch candidate |

These findings make the shortlist creative inspiration rather than a ready brand recommendation. None is treated as available. Keep the software name-neutral and run a fresh naming/clearance round before announcing a public identity; that commercial selection does not block the application architecture.
