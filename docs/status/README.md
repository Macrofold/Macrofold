[Scheduling](../features/execution/scheduling.md) owns policy and measured load evidence.

[Workflow waiting/history](../features/execution/workflow-history.md) keeps blocked work in PostgreSQL with adaptive expiry-bounded backoff. Migrations 026–027 add ownership and reassert the 24-hour default without rewriting accepted deadlines, terminal history or reservations.

It preserves detailed per-run streaming and replay. Migration 025 adds current resource revision stamps and indexes, without an event-log table or another service.
