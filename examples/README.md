# Runnable application examples

These examples use the public SDK and existing resource boundaries. Start with local synthetic data; no example enables paid execution or provisions a cloud service.

- [Personal agent](personal-agent/README.md): complete Alice/Milo application, scoped search connection, persistent files, multiple conversations, weekly schedule, pause/delete and interrupted-action recovery.
- [Customer-data recipes](integrations/README.md): Supabase RLS, real Prisma queries, Pinecone namespace isolation and an authenticated remote MCP server.
- [File memory helper](shared/file-memory.ts): configurable starter layout and a validated task-file schema, explained in the [memory guide](../docs/features/customer-agents/memory.md).

For design context, read [customer identity](../docs/features/customer-agents/README.md). The guides are explicitly published through [documentation navigation](../docs/navigation.json), including Markdown and AI exports. They identify production adoption steps and the source/test files to read together.
